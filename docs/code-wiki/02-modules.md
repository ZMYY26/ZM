# 第二章 主要模块职责

## 2.1 index.html —— 页面骨架

单文件包含全部界面，由 7 个 `.page` 区块和底部 `bottom-nav` 组成：

- `pageHome`：错题列表首页，含统计条（总错题/待复习/已掌握）与语言/考点/状态筛选。
- `pageCategory`：按考点标签云 + 按语言分类的横向统计条。
- `pageKnowledge`：知识库，含搜索框与分类标签、知识点卡片列表。
- `pageReview`：复习计划视图（艾宾浩斯时间线）。
- `pageEdit`：添加/编辑错题的表单页（标题、语言、描述、错误/正确代码、图片、标签、笔记、来源）。
- `pageDetail`：错题详情容器（由 JS 动态填充）。
- `pagePractice`：练习页（统计条 + 分类筛选 Tabs + 练习题列表）。

另有 5 个 `.modal-overlay` 弹窗：`searchModal`（搜索）、`knowledgeModal`（知识点详情）、`practiceModal`（答题）、`aiModal`（AI 举一反三）、`aiSettingsModal`（AI 配置）。

底部 Tab 栏对应 5 个主导航：错题本、分类、知识库、练习、复习。

## 2.3 practice-data.js —— 内置题库数据

定义全局常量 `PRACTICE_QUESTIONS`，数组内含 40 道单选题（id `q01`~`q40`），用于「练习」与「AI 举一反三」的基础题库。

每条题目结构：

```js
{
  id: 'q01',                 // 题目唯一标识
  category: '数据结构',       // 分类：数据结构/算法/操作系统/计算机网络/数据库/软件工程/计算机组成
  topic: '数组',             // 主题标签
  difficulty: 1,            // 难度 1~3
  type: 'choice',           // 题型（当前均为单选）
  question: '题干…',
  options: ['A', 'B', 'C', 'D'],
  answer: 1,                 // 正确答案下标（0 起）
  explanation: '解析…',
  related: ['q02', 'q03']    // 相关（同类/延伸）题目 id
}
```

`app.js` 中 `getAllPracticeQuestions()`（L1566）会将内置题库与 AI 生成的题目合并后返回。

## 2.4 app.js —— 核心逻辑

是项目「大脑」，按功能拆分为多个子模块，详见第 3 章。总体职责：

1. 错题数据的增删改查与本地持久化。
2. 基于艾宾浩斯遗忘曲线计算每个错题的下一复习日期。
3. 页面间导航、标题与返回按钮的动态切换。
4. 各页面视图渲染（列表 / 分类 / 复习 / 知识库 / 练习 / 详情）。
5. 全局搜索与多条件筛选。
6. 内置题库的练习、作答、判分、推荐下一题。
7. 调用 OpenAI 兼容 LLM 生成「举一反三」变式题。
8. 在浏览器内运行错题的 JS / Python 代码。
