# 电商商品价格自动化采集与对比工具

从主流电商平台（京东 / 淘宝 / 拼多多）批量抓取指定商品的**名称、价格、销量、店铺评分、网址链接**等关键信息，支持按关键词搜索采集；采集后自动**清洗去重、按价格从低到高排序**，并输出**商品横向对比、价格趋势图表、性价比推荐标注**。

提供两种使用形态：
- **命令行工具**（`python -m pricegrabber fetch "关键词"`）
- **演示网页**（`python -m pricegrabber server`，输入关键词后现场运行脚本）

> ⚠️ 真实平台（京东/淘宝/拼多多）反爬严格，脚本默认使用**确定性 Mock 数据源**（以关键词为种子，生成与真实数据形态一致的样本），因此离线 / 无授权环境也能完整演示。加 `--real` 尝试真实抓取，失败自动回退 Mock。

## 整体架构设计

```
┌─────────────┐   关键词    ┌─────────────────────────────────────────────┐
│   CLI/网页   │───────────▶│  AcquisitionManager（数据获取层）            │
└─────────────┘             │  ┌────────┐ ┌────────┐ ┌────────┐ ┌───────┐│
        ▲                   │  │ 京东    │ │ 淘宝    │ │ 拼多多  │ │ Mock  ││
        │                   │  └───┬────┘ └───┬────┘ └───┬────┘ └──┬────┘│
        │                   │  并行抓取│      │        │ 失败回退│     │
        │                   │       └────────┴────────┴─────────┘     │
        │                   └──────────────────┬──────────────────────┘
        │                                     ▼
┌───────┴────────┐   JSON    ┌────────────────────────────────────────────┐
│   渲染展示       │◀─────────│  数据处理流水线 pipeline.analyze()          │
│  ECharts 图表   │          │  清洗→去重→价格升序→性价比评分→对比→趋势   │
└────────────────┘           └──────────────────────────┬─────────────────┘
                                                        │ 写入快照
                                                        ▼
                                            ┌───────────────────────┐
                                            │  SQLite 价格历史(store)│
                                            └───────────────────────┘
```

**分层职责：**
1. **数据获取层（acquisition）**：`AcquisitionManager` 用线程池并行调用各平台 `BaseFetcher`；任一平台失败即回退到 `MockFetcher`，保证结果完整。`MockFetcher` 用 `HASH(keyword, 日期)` 作种子，**同一天结果稳定、跨天轻微波动**，可复现。
2. **数据处理层（processing）**：`clean_products` 清洗无效价格并去重 → `sort_by_price` 价格升序 → `score_products` 性价比评分标注 → `build_comparison` 横向对比 → `build_trends` 趋势。
3. **存储层（store）**：SQLite 每次搜索写入商品快照，多次运行可累积**真实历史价格**用于趋势。
4. **展示层（CLI / Web）**：CLI 用文本表格 + 对比表；Web 用 ECharts 呈现实时采集结果。

## 数据获取核心逻辑

- **统一接口**：所有采集器继承 `BaseFetcher.search(keyword, limit) -> PlatformSource`。
- **真实抓取器**（[jd.py](pricegrabber/acquisition/jd.py) 等）：实现真实 HTTP 请求与解析骨架；因平台强反爬，给出明确失败信号，由 `manager.py` 统一回退。
- **确定性与兜底**（[mock.py](pricegrabber/acquisition/mock.py)）：无需网络即可产出结构一致的商品数据（价格/销量/评分/店铺/链接/仓库），保证工具任何环境可用。

## 数据清洗 / 去重 / 排序

- 价格规整（去逗号、取第一位浮点）、销量处理 `万/千` 单位、评分范围校验。
- 标题归一化（去空格/符号/大小写）后按 `(平台, 标题)` 去重。
- 价格 `<=0` 的脏数据剔除；最终按**价格从低到高**排序并写入 `rank`。

## 性价比评分（推荐标注）

>`score = 0.50×价格(越低越好) + 0.25×销量 + 0.25×评分`（在该批结果内 min-max 归一化）

| score 区间 | 标注 |
|---|---|
| ≥85 | 性价比之王 |
| 70–85 | 超值推荐 |
| 55–70 | 均衡之选 |
| 40–55 | 表现平平 |
| <40 | 溢价偏高 |

## 可视化方案

网页使用 **ECharts**：
- **平台横向对比**：柱状图（各平台均价）+ 折线（平均评分），下方配对比明细表（最低/平均/最高价、销量、评分）。
- **价格趋势**：近 14 天折线图（代表商品逐日价格 + 最高/最低波动标记）。
- **性价比标注**：表格「性价比」列彩色标签 + 顶部「性价比之选」推荐卡片。

## 快速开始

```bash
pip install -r requirements.txt

# 命令行工具（演示模式）
python -m pricegrabber fetch "无线耳机"
python -m pricegrabber fetch "机械键盘" -p 8 -o result.json   # 每平台8条，导出JSON
python -m pricegrabber fetch "手机" --real                       # 尝试真实抓取(失败回退)

# 演示网页（打开 http://localhost:8000）
python -m pricegrabber server --port 8000
```
